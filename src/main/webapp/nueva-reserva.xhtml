¿Cómo registrar una reserva?

Ingresa el DNI, nombre y teléfono del cliente.

Selecciona una cancha, fecha y horario disponible. Puedes consultar la disponibilidad en el calendario.

Si el horario ya está reservado, el sistema mostrará un aviso y deberás elegir otro.

Selecciona Yape, Plin o Efectivo e ingresa el monto. El código de pago es opcional.
